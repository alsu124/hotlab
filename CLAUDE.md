# CLAUDE.md — сайт HOT LAB (hotlabstudio.ru)

Статический сайт студии HOT LAB. Хостинг — **GitHub Pages**.
Репозиторий: **`alsu124/hotlab`**, ветка: **`main`**, домен: **hotlabstudio.ru**.

## ⚠️ Главное правило
Любые правки сайта вносятся **только в этот репозиторий (`alsu124/hotlab`) и только в ветку `main`**.
**Никогда не создавай новый репозиторий и новую ветку** для правок — иначе изменение не попадёт на сайт.

## Расписание групповых занятий
Единственный источник расписания — файл **`schedule.json`** в корне репозитория.

Структура:
```json
{
 "days": {
  "mon": [ { "time": "18.30", "name": "Горячая Йога 36'" }, ... ],
  "tue": [ ... ], "wed": [...], "thu": [...],
  "fri": [...], "sat": [...], "sun": [...]
 }
}
```
- Ключи дней: `mon tue wed thu fri sat sun` (пн…вс).
- Время — через точку: `"9.00"`, `"18.30"`.
- Апостроф в «36'» — прямой `'` (U+0027).

**Чтобы изменить расписание:**
1. Отредактируй `schedule.json` (меняй только `time`/`name`, структуру не ломай).
2. Закоммить в ветку **`main`** репозитория `alsu124/hotlab`.
3. Проверь, что запустился GitHub Actions.

## Как публикуется (деплой автоматический)
Пуш в `main` → workflow **`.github/workflows/schedule.yml`** запускает **`tools/render_schedule.py`**,
который рендерит расписание из `schedule.json` на страницы сайта → затем GitHub Pages публикует.
**Ничего деплоить вручную не нужно.** Через 1–2 минуты сайт обновится (проверка: hotlabstudio.ru, обновить Cmd/Ctrl+Shift+R).
